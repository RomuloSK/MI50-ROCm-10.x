# Security policy

Please do not publish credentials, private hardware logs, or exploitable
details about an unpatched vulnerability in a public issue. Report security
issues privately through the repository owner's GitHub security contact (or a
private security advisory when enabled), including the affected commit,
reproduction steps and impact.

This project does not ship AMD firmware or replace the Linux kernel driver.
Only obtain firmware and third-party sources from their official distribution
channels, and verify the recorded source and artifact hashes before use.
